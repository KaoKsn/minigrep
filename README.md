# minigrep

This projects contains a pure Rust simple implemention of the legendary `grep` unix command.

This was written in an effort to learn the [Rust](https://rust-lang.org) Programming Language using the official `Book` which can be found [here](https://doc.rust-lang.org)

You can navigate to Week 12 which contains snippets and guidance to implement this project.

Learn more about `grep` [here](https://en.wikipedia.org/wiki/Grep)
